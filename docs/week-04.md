## ③ Acceptance Criteria

최소 정상 경로 2개 + 실패 경로 1개. **판정 방법** 칸이 비면 아직 명세가 아닙니다.
At least two normal paths + one failure path. If "How to check" is empty, it is not yet a spec.

| # | 경로 Path | EARS 문장 Sentence | 판정 방법 How to check |
|---|---|---|---|
| *예시* | *정상* | *WHEN 학생이 과제 목록을 열면 THE 시스템은 SHALL 과목별 미제출 과제를 마감일 순으로 표시한다* | *미제출 과제 3건을 만든 뒤 목록을 열어 마감일 순으로 나오는지 확인* |
| AC-１ | 정상 Normal | WHEN 사용자가 브라우저 새 탭을 열면 THE 시스템은 SHALL 저장된 모든 북마크를 사용자가 따로 조작하지 않아도 주제 그룹(예: 과제, 공부, 자주 쓰는 사이트)으로 묶어 표시한다  | 폴더 없이 서로 다른 주제의 북마크 30개를 저장한 뒤 새 탭을 열어, 30개가 빠짐없이 표시되고 3개 이상의 그룹으로 나뉘는지 확인 |
| AC-２ | 정상 Normal | WHEN 사용자가 새 탭에서 북마크 항목을 클릭하면 THE 시스템은 SHALL 해당 페이지를 클릭 1회로 연다  | 새 탭에서 임의의 북마크 5개를 각각 클릭해, 모두 1클릭으로 올바른 URL이 열리는지 확인 |
| AC-３ | 정상 Normal | WHEN 새 탭에 북마크가 표시되면 THE 시스템은 SHALL 각 북마크에 제목과 함께 사이트 주소(도메인)와 저장 날짜를 표시한다 | 북마크 10개를 표시한 뒤 각 항목에 제목, 도메인, 저장 날짜가 모두 나오는지 확인 |
| AC-４ | 실패 Failure | IF 북마크의 주제를 판별할 수 없으면 THEN THE 시스템은 SHALL 해당 북마크를 '기타' 그룹에 표시하고 화면에서 누락하지 않는다 | 제목과 URL로 주제를 알 수 없는 북마크(예: 제목 "새 탭", 단축 URL) 3개를 저장한 뒤 새 탭을 열어 '기타' 그룹에 3개가 모두 보이는지 확인 |
| AC-５ | 정상 Normal | WHEN 사용자가 새 북마크를 저장하면 THE 시스템은 SHALL 다음에 새 탭을 열 때 해당 북마크를 알맞은 그룹에 포함해 표시한다  | 공부 관련 페이지 1개를 새로 북마크한 뒤 새 탭을 열어 '공부' 그룹에 나타나는지 확인 |
| AC-６ | 정상 Normal | IF 사용자가 북마크 접근 권한을 허용하지 않으면 THEN THE 시스템은 SHALL 새 탭에 권한이 필요한 이유와 권한 허용 버튼을 표시한다 | 확장 프로그램 설치 시 권한을 거부한 뒤 새 탭을 열어 안내 문구와 허용 버튼이 표시되는지, 버튼을 누르면 권한 요청 창이 뜨는지 확인 |
