# 팀 규칙 / Team Rules

1주차 활동지(week-01.md)에서 합의한 내용을 여기에 정리합니다.
*Copy the agreements from week-01.md here.*

1. 연락 규칙
- 카카오톡 (기본 소통 및 연락용도)
- 디스코드 (비대면 회의시, 사정으로 인해 대면회의가 어려울경우 사용)
- 메시지 확인 후 3시간 이내 응답, 22시 이후 연락 자제(마감 2일전 제외)
2. 회의 규칙
- 정기 회의 시간: 
- 지각 예정이면 최소 1시간 전에 사전 연락, 사유 설명
3. 기여 규칙
- 각 할당된 양의 절반 이상(50%)은 끝낼것
4.갈등 처리
- 의견 투표, 모든 의견이 서로 다르거나, 투표후 동표발생시 팀장 의견 우선
5. 마감 규칙
- 마감 기한 설정: 제출 1~2일전 마감 (늦어도 제출 12시간 전까지)
- 일정 지연 시 조치: 마감 24시간 전까지 사전 공유 및  현재 완성도를 알리고 역할 분담 재조정
