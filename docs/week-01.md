## 기여 규칙 / Contribution rule — 1인당 주 최소 작업량 
- 각 할당된 양의 절반 이상(50%)은 끝낼것

## 갈등 처리 / Conflict rule — 의견이 갈릴 때 (개인의견작성)
- 의견 투표, 모든 의견이 서로 다르거나, 투표후 동표발생시 팀장 의견 우선

## 마감 규칙 / Deadline rule 
- 마감 기한 설정: 제출 1~2일전 마감 (늦어도 제출 12시간 전까지)
- 일정 지연 시 조치: 마감 24시간 전까지 사전 공유 및  현재 완성도를 알리고 역할 분담 재조정

## **팀 공용 언어 / Working language** — 회의 언어 / 기록 언어
- 회의 언어: 한국어
- 기록 언어: 한국어/영어

## AI 사용에 대한 팀 합의 / Team agreement on AI use 
- 찬성요소: 코딩 보조, 코드 생성 시 검증, 자료조사, 정리 허용, 아이디어 검증및 구체화
- 반대요소: 아이디어 구상
- 주의점: 코드를 만들더라도 만들고 나서 꼭 코드내용을 이해할 것

## 성찰 / Reflection — 가장 걱정되는 것 
- 박현: 팀장으로써 이 팀을 잘 이끌 수 있을 것 인가, 깃허브 사용이 익숙하지 않아서 이걸 수월하게 배우고 활용할 수 있을 것 인가
- 제빈 : 나의 역량 부족으로 팀원들의 발목을 잡지는 않을까
- 윤성 : 나의 능력 부족으로 팀의 발목을 붙잡지 않을까
- 승엽 : 나의 능력 부족이 팀을 힘들게 하지 않을까
