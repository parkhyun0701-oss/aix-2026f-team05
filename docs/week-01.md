## 연락 규칙 / Contact rule — 어디로, 몇 시간 내 응답
### 주요 소통 채널
- 카카오톡
- 디스코드(사용여부 결정)
### 기본 응답 시간
- 메시지 확인 후 3~4시간 이내 응답, 22시 이후 연락 자제(특정한 상황재외)

## 회의 규칙 / Meeting rule — 요일·시간·불참 처리 (개인의견작성)
### 회의 가능한 시간(정기회의)
- 박현: 월, 목, 금, 주말(토)



### 불참 및 지각 처리 (개인의견작성)
- 박현: 최소 1~2시간 전 사전 공유, 지각 시 사유 설명


## 기여 규칙 / Contribution rule — 1인당 주 최소 작업량 



## 갈등 처리 / Conflict rule — 의견이 갈릴 때 (개인의견작성)
- 박현: 의견투표, 조장의견결정


## 마감 규칙 / Deadline rule 
- 마감 기한 설정: 제출 1~2일전 마감 준
- 일정 지연 시 조치: 마감 24시간 전 사전 공유 및 역할 분담 재조정

## **팀 공용 언어 / Working language** — 회의 언어 / 기록 언어
- 회의 언어: 한국어
- 기록 언어:한국어/영어

## AI 사용에 대한 팀 합의 / Team agreement on AI use (개인의견작성)
- 박현: 코딩 보조, 코드 생성 시 검증 필수, 아이디어 구상은 반대, 개인/팀이 생각한뒤 ai에게 아이디어 검증및 구체화는 허용
