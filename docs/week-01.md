## 연락 규칙 / Contact rule — 어디로, 몇 시간 내 응답
### 주요 소통 채널
- 카카오톡
- 디스코드, 대면(사용여부 결정)
- 제빈 : 주 연락 수단은 카카오톡을 활용, 온라인 회의 시 디스코드 활용
- 윤성 : 주 연락 카톡, 비대면 회의 디스코드
### 기본 응답 시간
- 메시지 확인 후 3~4시간 이내 응답, 22시 이후 연락 자제(특정한 상황재외)
- 제빈 : 메세지 확인 후 2시간 이내 응답, 22시 이후 연락 자제(마감 1일~2일전 재외)
- 윤성 : 확인후 3시간전까지 답장, 22시 이후 연락 자제

## 회의 규칙 / Meeting rule — 요일·시간·불참 처리 (개인의견작성)
### 회의 가능한 시간(정기회의)
- 박현: 월, 목, 금, 주말(토)
- 제빈 : 월(20시 이후), 목 ,주말(토, 일 모두 19시 이후) 가능
- 윤성 : 월, 목, 주말


### 불참 및 지각 처리 (개인의견작성)
- 박현: 최소 1~2시간 전 사전 공유, 지각 시 사유 설명
- 제빈 : 최소 2시간 전 사전 공유 및 사유 설명
- 윤성 : 최소 1시간 전에 사전 연락, 사유 설명(이유 없이 결석시 전화 폭격)

## 기여 규칙 / Contribution rule — 1인당 주 최소 작업량 
- 윤성 : 각 할당된 양의 절반 이상은 끝낼것


## 갈등 처리 / Conflict rule — 의견이 갈릴 때 (개인의견작성)
- 박현: 의견투표, 조장의견결정
- 제빈 : 투표 후 동표라면 팀장의견 우선시
- 윤성 : 의견이 갈릴시 각 의견에 대한 이유를 설명한뒤 투표


## 마감 규칙 / Deadline rule 
- 마감 기한 설정: 제출 1~2일전 마감 준
- 일정 지연 시 조치: 마감 24시간 전 사전 공유 및 역할 분담 재조정

## **팀 공용 언어 / Working language** — 회의 언어 / 기록 언어
- 회의 언어: 한국어
- 기록 언어:한국어/영어

## AI 사용에 대한 팀 합의 / Team agreement on AI use (개인의견작성)
- 박현: 코딩 보조, 코드 생성 시 검증 필수, 아이디어 구상은 반대, 개인/팀이 생각한뒤 ai에게 아이디어 검증및 구체화는 허용
- 윤성 : 코딩 보조, 검수, 자료조사, 자신의 의견 구체화



## 성찰 / Reflection — 가장 걱정되는 것 (개인의견작성)
- 박현: 팀장으로써 이 팀을 잘 이끌 수 있을 것 인가, 깃허브 사용이 익숙하지 않아서 이걸 수월하게 배우고 활용할 수 있을 것 인가
- 제빈 : 나의 역량 부족으로 팀원들의 발목을 잡지는 않을까
- 윤성 : 나의 능력 부족으로 팀의 발목을 붙잡지 않을까
